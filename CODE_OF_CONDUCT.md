# Code of Conduct

Contributors are expected to be respectful, inclusive, and constructive. Give feedback about the HTML, CSS, or documentation rather than about a person, and welcome different levels of experience.

Harassment, discrimination, personal attacks, deliberate disruption, publishing private information, and hostile behavior are not acceptable.

Report concerns privately to the repository maintainer, Brajesh Kumar (`brajesh31`). Maintainers may remove content or restrict participation when necessary to protect a welcoming project community.
