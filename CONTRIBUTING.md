# Contributing

Thank you for contributing to the Advanced CSS assignments.

## Workflow

1. Read the README and inspect the relevant task.
2. Create a focused branch for your change.
3. Keep examples self-contained and avoid unrelated formatting changes.
4. Test the page in a current browser at multiple viewport widths.
5. Check keyboard navigation, contrast, and focus visibility.
6. Update the corresponding output image only when the visual result intentionally changes.

## Pull requests

Describe the task changed, the CSS technique demonstrated, browsers and viewport sizes tested, and any accessibility considerations. Do not commit editor metadata, private assets, or generated temporary files.

## Style

Prefer semantic HTML, readable class names, consistent indentation, and CSS that explains the intended layout. Keep external dependencies out of the exercises unless the change is documented and necessary.
