# Roadmap

## Near term

- Add task-specific descriptions and learning objectives.
- Add browser and viewport notes for each output image.
- Review color contrast, keyboard focus, and reduced-motion behavior.
- Remove editor-specific metadata from future commits.

## Later

- Introduce shared, documented design tokens only when exercises benefit from reuse.
- Add responsive test cases and accessible semantic markup.
- Publish a small gallery linking each task to its expected output.

The project remains intentionally lightweight and static; a build system is not planned unless the number of exercises requires one.
