## 📍 Current State

The repository contains five standalone HTML pages and corresponding PNG output references. Examples cover CSS custom properties, a 3D cube, a circular loader, visibility, and a fifth image-led exercise.

There is no build system, application framework, automated browser test suite, backend, or database.

## 📘 Content and Learning

- [ ] Add learning objectives and expected outcomes to each task.
- [ ] Add concise explanations for each important CSS declaration.
- [ ] Add small follow-up experiments for beginners.
- [ ] Explain common CSS mistakes and how to debug them.
- [ ] Expand the task catalogue when new exercises are added.

## 🎨 CSS Correctness

- [ ] Review all examples for valid CSS values.
- [ ] Clarify transform order and perspective behaviour in the cube exercise.
- [ ] Add responsive variants where appropriate.
- [ ] Demonstrate fallback values for CSS custom properties.
- [ ] Compare visibility, display, and opacity with an interactive example.

## ♿ Accessibility

- [ ] Add reduced-motion handling to continuous animation examples.
- [ ] Improve informative image alternative text.
- [ ] Test keyboard focus if interactive controls are introduced.
- [ ] Document contrast and zoom checks.

## 🧪 Visual Validation

- [ ] Record viewport dimensions used for each reference image.
- [ ] Keep screenshots aligned with the current source.
- [ ] Document browser differences that materially affect output.
- [ ] Introduce automated browser checks only if the collection grows enough to justify them.

## 🧹 Repository Maintenance

- [ ] Keep editor-specific files out of future commits.
- [ ] Review README timestamp automation for unnecessary commits.
- [ ] Keep documentation links synchronized.
- [ ] Keep task examples standalone and dependency-free unless justified.

## 💡 How to Propose Work

Open a focused issue describing the learner problem, expected CSS behaviour, affected task, visual result, and validation approach.
