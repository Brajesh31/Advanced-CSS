# Security Policy

This repository contains static HTML and CSS exercises and does not process accounts, credentials, or server-side data.

## Reporting

Do not publish exploitable security issues or private information in a public issue. Contact Brajesh Kumar (`brajesh31`) privately with the affected file, reproduction steps, impact, and suggested mitigation.

## Safe contributions

Review external links and assets before adding them. Do not commit credentials, tracking identifiers, malicious scripts, private files, or untrusted generated content. Test pages locally before publishing them.
