# 📚 Advanced CSS Documentation

This directory contains practical guides for the standalone HTML and CSS assignments in this repository. The project has no package manager, build pipeline, database, server-side API, or application runtime beyond the browser.

## 📖 Guides

| Document | Purpose |
|---|---|
| [Installation](installation.md) | Open HTML files and run a local static server |
| [Architecture](architecture.md) | Understand the repository structure and execution model |
| [Development](development.md) | Modify tasks and validate changes |
| [FAQ](faq.md) | Answers to common questions |
| [Troubleshooting](troubleshooting.md) | Diagnose path, CSS, animation, and browser issues |
| [Deployment](deployment.md) | Publish the static exercise collection |
| [API scope](api.md) | Clarify why the repository has no API |
| [Database scope](database.md) | Clarify why the repository has no database |

## 🧭 Recommended reading

**For learners:** start with the root [README](../README.md), then open a task and compare it with its output screenshot.

**For contributors:** read [CONTRIBUTING](../CONTRIBUTING.md), [Development](development.md), and [Architecture](architecture.md).

**For maintainers:** review [Security](../SECURITY.md), [Support](../SUPPORT.md), [Roadmap](../ROADMAP.md), and [Changelog](../CHANGELOG.md).

## 🎯 Scope

Documentation describes the files currently present. It must not claim that a task includes functionality that is only proposed. The examples should remain simple enough to inspect and run without installing a framework.
