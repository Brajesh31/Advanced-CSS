# Architecture

Advanced-CSS is a static exercise repository. Each task is an independent HTML document with embedded or local CSS, and each output image records an expected visual result.

```text
Assignment_13_Advanced CSS/
  Task_1.html ... Task_5.html
  Output/
    task_1.png ... task_5.png
```

There is no application server, database, build pipeline, or runtime API. Browser rendering is the execution environment. Changes should preserve task isolation unless shared assets are intentionally introduced and documented.
