# Deployment

The repository can be published as a static site. No server-side runtime or build step is required.

## Static hosting checklist

1. Publish the repository contents through a trusted static host.
2. Confirm the `Assignment_13_Advanced CSS` path and spaces are handled correctly.
3. Test every task page and image link from the hosted URL.
4. Enable HTTPS and review external assets before publishing.
5. Keep source HTML and expected output images synchronized.

Do not publish secrets, private assets, or unreviewed third-party scripts.
