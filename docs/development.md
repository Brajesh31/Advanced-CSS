# Development

Use a focused task branch and keep each HTML exercise easy to open independently. Make small CSS changes, then refresh the page at narrow and wide viewport sizes.

Before submitting:

- check the browser console for errors;
- verify keyboard focus remains visible;
- check text and controls for readable contrast;
- compare the rendered result with the matching `Output` image;
- run `git diff --check`;
- remove editor metadata and temporary files.

Document any intentional visual differences in the pull request.
