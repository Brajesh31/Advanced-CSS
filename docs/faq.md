# Frequently asked questions

## Do I need Node.js?

No. The current tasks are static HTML and CSS files.

## Do I need to install dependencies?

No. You can open the pages directly or use Python's built-in static server.

## Why are output PNGs committed?

They provide visual references for the corresponding tasks and help reviewers identify intentional changes.

## Can I combine the tasks into one application?

You may build a gallery as a separate, documented change, but keep the original standalone exercises intact.
