# Installation

No package installation is required. The exercises are standalone HTML files.

## Optional local server

To serve the repository from a predictable origin, use Python:

```powershell
py -m http.server 8000
```

Open the task pages under `http://localhost:8000/Assignment_13_Advanced%20CSS/`.

You can also open an HTML file directly in a browser. A local server is preferable when future exercises use relative assets or browser APIs that require an origin.
